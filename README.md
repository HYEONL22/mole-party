# 치고박고

초대한 친구끼리만 하는 웹 두더지잡기. 모자 쓴 도트 캐릭터의 모자 색·반팔티 색을 고를 수 있다.

> 현재 **4단계까지 완료**: 방에서 친구들과 실시간으로 같이 한 판 → 결과/순위 → 같은 방에서 다시 하기,
> 효과음·타격 이펙트·폰 터치 다듬기·재접속 처리. 혼자 연습하기도 있다.

## 로컬 실행

필요: Node.js 20 이상

```bash
npm install
npm run dev
```

화면(5173)과 게임 서버(3001)가 함께 켜진다. 터미널에 뜨는 주소로 접속한다.
- PC: `http://localhost:5173`
- 같은 와이파이의 폰: `Network:` 줄의 `http://192.168.x.x:5173`

기타 명령
- `npm run typecheck` — 타입 검사
- `npm run build` — `dist/`에 화면 파일 생성
- `npm start` — 배포용 실행 (서버 하나가 화면 + 게임 서버를 함께 제공, `PORT` 환경변수 사용)

## 2단계 확인 방법

PC 브라우저 탭 두 개, 또는 PC + 폰으로 확인한다.

1. **방 만들기**: 닉네임 입력 → [방 만들기] → 대기실에 5자리 코드와 내 캐릭터(👑 방장)가 보인다.
2. **링크 초대**: [🔗 초대 링크 복사] → 다른 탭/폰에서 그 주소를 연다 → 저장된 닉네임과 캐릭터로 **바로 입장**한다.
   - 저장된 닉네임이 없으면 시작 화면에 코드가 채워진 채로 닉네임을 물어본다.
3. **코드로 참가**: 시작 화면의 코드 칸에 5자리 입력 → [참가].
4. **닉네임 중복**: 같은 방에 같은 닉네임이 있으면 입장이 막히고 안내가 뜬다.
   (같은 PC의 두 탭은 저장된 닉네임을 같이 쓰므로, 두 번째 탭에서 바로 확인 가능)
5. **캐릭터 바꾸기**: 대기실에서 색을 바꾸고 저장 → 다른 사람 화면에도 바로 반영.
6. **새로고침**: 대기실에서 새로고침 → 같은 자리로 돌아온다 (중복 입장 안 됨).
   창을 닫으면 60초 동안 "연결 끊김"으로 보이다가 빠진다.
7. **방장 위임**: 방장이 [나가기] → 다음 사람이 👑 방장이 된다. 모두 나가면 방이 사라진다.
8. 최대 8명. 게임 중인 방에는 새로 들어올 수 없다 (끝나면 가능).

## 3단계 확인 방법 (같이 하기)

1. 두 명 이상 대기실에 모인 상태에서 방장이 **[게임 시작]** → 모두 동시에 3·2·1 카운트다운.
2. 같은 두더지를 둘이 거의 동시에 누르면 **서버에 먼저 도착한 한 명만** 점수를 얻는다.
   다른 사람이 잡은 두더지 위에는 그 사람 닉네임이 뜬다.
3. 위쪽 점수판이 모두의 점수를 실시간으로 보여 준다.
4. 시간이 끝나면 모두 같은 결과 화면(순위, 동점은 공동 순위). **[같은 방에서 다시 하기]** → 대기실 → 방장이 다시 시작.
   결과 화면을 보고 있는 동안 방장이 시작하면 바로 같이 들어간다.
5. **게임 중 새로고침** → 그 사람은 이번 판에서 빠지고 대기실에서 "지금 게임 중" 안내를 보며 기다린다.
   다른 사람 화면에는 "나감"으로 표시되고, 판이 끝나면 결과를 같이 본다.
6. 게임 중 [대기실] 버튼도 같은 동작 (점수는 남지만 더 이상 누를 수 없음).

## 4단계 확인 방법 (소리·이펙트·폰·재접속)

1. **효과음**: 카운트다운 삑삑 → 시작, 두더지 종류마다 다른 소리(일반/황금/번개/가짜/폭탄),
   콤보·피버 타임·마지막 5초 째깍·끝나는 팡파레. 다른 사람이 잡으면 작은 소리.
   - 오른쪽 위 🔊 버튼으로 끄고 켤 수 있다 (진동도 같이 꺼짐). 설정은 기억된다.
   - 폰은 화면을 한 번 터치해야 소리가 나기 시작한다 (브라우저 규칙). 무음 모드면 iPhone은 소리가 안 날 수 있다.
2. **타격 이펙트**: 누른 곳에 뿅망치가 내려친다. 황금은 반짝이 입자, 일반은 흙 튐, 폭탄은 빨간 번쩍임 + 흔들림.
3. **진동**(안드로이드만): 잡으면 짧게, 가짜는 조금 길게, 폭탄은 두두둥. iPhone은 브라우저가 진동을 지원하지 않는다.
4. **폰 화면**: 게임 화면이 스크롤 없이 한 화면에 들어온다(작은 폰 포함). 빠르게 연타해도 확대되지 않고,
   길게 눌러도 메뉴가 뜨지 않으며, 당겨서 새로고침도 막혀 있다. 게임 중에는 화면이 꺼지지 않는다(지원 브라우저).
   두 손가락으로 두 구멍을 동시에 눌러도 각각 처리된다.
5. **재접속**:
   - 대기실에서 카톡으로 링크를 보내러 갔다 와도(60초 이내) 같은 자리로 돌아온다. 위에 "다시 연결하는 중…"이 잠깐 보인다.
   - 60초가 지나 자리가 없어졌으면 같은 닉네임으로 자동으로 다시 들어간다 (대기실일 때).
   - 서버가 재시작돼서 방이 사라졌다면 "방에 다시 들어가지 못했어요" 안내와 함께 시작 화면으로 간다.
   - 게임 중 연결이 끊기면 대기실로 돌아가고, 판이 끝나면 결과를 같이 본다.

판정 방식
- 서버가 두더지 출현 일정을 만들고, 누가 먼저 눌렀는지·점수 계산을 모두 서버가 한다.
- 화면은 누르는 즉시 타격 효과를 보여 주고, 점수는 서버 응답이 오면 확정한다.
- 접속할 때 서버와 시계를 맞춰서(핑 6번), 폰마다 시계가 달라도 두더지가 같은 순간에 나온다.
- 두더지가 들어간 직후 0.15초까지 도착한 타격은 인정한다 (네트워크 지연 보정).

## 배포 (Render 무료 플랜)

서버 1대가 화면과 게임 서버를 함께 맡는다. 결과로 `https://mole-party-xxxx.onrender.com` 같은 주소가 생기고,
이 주소(초대 링크)만 친구에게 보내면 된다.

1. 이 폴더를 GitHub 저장소로 올린다 (비공개 저장소도 가능).
2. https://render.com 가입 → **New + → Blueprint** → 저장소 선택.
   `render.yaml`을 읽어 설정이 자동으로 채워진다 → **Apply**.
3. 몇 분 뒤 빌드가 끝나면 상단의 `…onrender.com` 주소로 접속.

알아둘 점
- 무료 플랜은 15분 동안 아무도 안 쓰면 잠든다. 그 뒤 첫 접속은 **30초~1분** 걸린다 (화면에 "서버가 잠에서 깨는 중" 표시).
- 방 정보는 메모리에만 있어서, 서버가 잠들거나 재시작되면 열려 있던 방은 사라진다.

## 게임 규칙

50초, 3x3 구멍. 규칙 숫자(시간, 확률, 점수)는 모두 `src/shared/game.ts` 맨 위에 모여 있다.

| 종류 | 생김새 | 점수 |
|---|---|---|
| 일반 두더지 | 갈색 | +1 |
| 황금 두더지 | 금색, 반짝임 | +3 |
| 번개 두더지 | 파란 회색, 이마에 번개. 0.45~0.65초만 나옴 | +2 |
| 가짜 두더지 | 일반과 비슷하지만 **빨간 코 + 찌푸린 눈썹** | −1 |
| 폭탄 | 검은 폭탄, 빨간 눈 | −2 (화면 흔들림) |
| 변신 두더지 | 황금으로 나왔다가 깜빡이며 **폭탄으로 변신** | 누른 순간의 모습대로 +3 / −2 |

- **콤보**: 감점 없이 5마리 연속마다 보너스 +2 (감점 두더지를 누르면 초기화)
- **피버 타임**: 마지막 10초. 두더지 2배로 자주, +점수 2배
- 점수는 0점 아래로 내려가지 않는다

## 구조

```
server/
  index.ts           HTTP(화면 파일) + WebSocket(/ws) + /healthz
  rooms.ts           방 생성/입장/재접속/방장 위임 (메모리)
src/
  shared/            서버와 화면이 같이 쓰는 코드
    avatar.ts        Avatar 타입(모자 색, 반팔티 색), 검증, 랜덤
    avatarParts.ts   ★ 캐릭터 도트·색 정의 — 색 추가는 여기서
    game.ts          게임 규칙: 출현 일정, 점수, 콤보, 피버, 순위
    engine.ts        한 판 진행·판정 (서버와 혼자 연습이 같이 씀)
    nickname.ts      닉네임 정리/중복 비교 규칙
    protocol.ts      실시간 메시지 규격
  client/
    net.ts           WebSocket 연결 + 서버 시계 맞추기 + 연결 살아있는지 확인
    sound.ts         효과음(Web Audio 합성) + 진동 + 음소거
    room.ts          방 상태, 입장/퇴장, 새로고침 후 복귀, 끊김 시 재연결, 이번 판 메시지 보관
    localSession.ts  게임 화면용 연결: LocalSession(혼자) / NetSession(같이)
    screens/         start, lobby, customize, game, result, connecting
scripts/dev.mjs      개발용 동시 실행
avatar-preview.html  (개발용) 캐릭터 색 조합 한눈에 보기: /avatar-preview.html
```

### 새로고침 처리
입장하면 서버가 비밀 토큰을 주고, 그 탭의 sessionStorage에 저장한다.
새로고침하면 이 토큰으로 같은 자리에 돌아간다. 서버는 끊긴 사람의 자리를 60초 동안 남겨 둔다.
게임 중에 새로고침하면 대기실로 돌아가 이번 판에서는 빠지고, 판이 끝나면 결과를 같이 본다.

## 홈 화면에 앱으로 추가 (PWA)

설치 없이 링크로 열지만, 홈 화면에 아이콘을 만들어 앱처럼 쓸 수 있다 (주소창 없는 전체 화면).
- **안드로이드(크롬·삼성인터넷)**: 시작 화면 아래 [📲 홈 화면에 앱 추가] 버튼 → 추가.
- **아이폰(Safari)**: 시작 화면 아래 안내대로 공유 버튼 → "홈 화면에 추가".
- **카카오톡 안에서 링크를 연 경우**: 카톡 브라우저에서는 추가가 안 된다. "다른 브라우저로 열기" 후 추가.

관련 파일
- `public/manifest.webmanifest` — 앱 이름·아이콘·전체 화면 설정
- `public/sw.js` — 서비스 워커 (설치 가능하게 + 인터넷이 잠깐 끊겨도 첫 화면은 뜨게)
- `public/*.png` — 아이콘. `node scripts/make-icons.mjs`로 다시 만들 수 있다
- `src/client/install.ts` — 설치 버튼/안내
